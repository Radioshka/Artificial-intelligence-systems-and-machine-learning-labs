# Лабораторная работа: регрессионный анализ и PCA

## 1. Назначение проекта

Данный репозиторий содержит программную реализацию лабораторной работы по машинному обучению.

Основная задача проекта — исследовать возможность прогнозирования **массы тела пингвина (`body_mass_g`)** по его морфологическим и категориальным характеристикам с использованием методов линейной регрессии.

В работе последовательно рассматриваются:

- первичный анализ и визуализация данных;
- обработка пропущенных значений;
- кодирование категориальных признаков;
- анализ корреляций;
- диагностика мультиколлинеарности с помощью VIF;
- Linear Regression;
- Ridge Regression;
- Lasso Regression;
- кросс-валидация;
- оценка качества по RMSE, R² и MAPE;
- стандартизация признаков;
- метод главных компонент (PCA);
- повторное обучение моделей после уменьшения размерности;
- сравнение результатов до и после PCA.

**Важно:** проект использует локальный CSV-файл и не требует регистрации, участия в соревновании или отправки решения на Kaggle.

---

## 2. Данные

В проекте используется файл:

```text
data/penguins.csv
```

Файл содержит 1000 наблюдений и 7 исходных столбцов.

### Переменные датасета

| Переменная | Тип | Описание |
|---|---|---|
| `species` | категориальная | вид пингвина |
| `island` | категориальная | остров |
| `culmen_length_mm` | числовая | длина клюва, мм |
| `culmen_depth_mm` | числовая | глубина клюва, мм |
| `flipper_length_mm` | числовая | длина ласты, мм |
| `body_mass_g` | числовая | масса тела, г |
| `sex` | категориальная | пол |

### Целевая переменная

В качестве целевой переменной выбрана:

```text
body_mass_g
```

То есть задача является **регрессионной**: модель должна предсказывать числовое значение массы тела пингвина.

`species` используется как один из признаков, а не как целевая переменная. Это позволяет сохранить постановку задачи регрессии и использовать Linear, Ridge и Lasso Regression вместе с RMSE, R² и MAPE.

## 6. Что выполняет программа

### Этап 1. Загрузка и проверка данных

Программа загружает CSV, проверяет наличие необходимых столбцов и выводит:

- размер выборки;
- количество пропущенных значений;
- описательную статистику целевой переменной.

### Этап 2. Первичный анализ

Создаются:

- гистограммы числовых переменных;
- boxplot массы тела по видам;
- scatter plots массы тела относительно морфологических признаков;
- корреляционная матрица.

### Этап 3. Предобработка

Для числовых признаков используется:

1. заполнение пропусков медианой;
2. стандартизация.

Для категориальных признаков:

1. заполнение пропусков наиболее частым значением;
2. One-Hot Encoding;
3. удаление первой dummy-категории.

Строки с отсутствующим `body_mass_g` удаляются перед обучением, поскольку целевую переменную нельзя корректно восстановить обычным preprocessing.

### Этап 4. Разделение данных

Используется разделение:

- 80% — обучающая выборка;
- 20% — тестовая выборка.

Используется `random_state=42` для воспроизводимости результатов.

### Этап 5. Анализ мультиколлинеарности

Для числовых предикторов рассчитывается VIF.

Полученные значения сохраняются в:

```text
results/vif.csv
```

### Этап 6. Регрессионные модели

Обучаются три модели:

```text
Linear Regression
Ridge Regression
Lasso Regression
```

Для Ridge и Lasso параметр регуляризации выбирается с помощью `GridSearchCV`.

### Этап 7. Кросс-валидация

Используется 5-fold cross-validation.

Критерий выбора модели при подборе гиперпараметров — RMSE.

### Этап 8. PCA

Перед PCA:

1. обрабатываются пропуски;
2. категориальные признаки кодируются;
3. все полученные признаки стандартизируются;
4. выполняется PCA.

Выбирается минимальное количество компонент, сохраняющее не менее 95% дисперсии.

### Этап 9. Повторное моделирование

После PCA снова обучаются:

- Linear Regression;
- Ridge Regression;
- Lasso Regression.

Результаты сравниваются с моделями, построенными до PCA.

## 7. Метрики

### RMSE

\[
RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2}
\]

Чем меньше RMSE, тем меньше ошибка прогнозирования.

### R²

\[
R^2 = 1-\frac{\sum(y_i-\hat y_i)^2}
{\sum(y_i-\bar y)^2}
\]

Показатель характеризует долю вариации целевой переменной, объясняемую моделью.

### MAPE

\[
MAPE =
\frac{100\%}{n}
\sum_{i=1}^{n}
\left|
\frac{y_i-\hat y_i}{y_i}
\right|
\]

Поскольку масса тела пингвинов положительна, MAPE применим к данной задаче.
