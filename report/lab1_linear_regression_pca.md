# Лабораторная работа: линейная регрессия, регуляризация и PCA

## 1. Введение

Цель работы — построить и сравнить модели линейной регрессии для прогнозирования массы тела пингвинов, а также исследовать влияние мультиколлинеарности и метода главных компонент (PCA) на качество моделей.

В работе рассматриваются:
- Linear Regression;
- Ridge Regression;
- Lasso Regression;
- кросс-валидация;
- RMSE;
- R²;
- MAPE;
- корреляционный анализ;
- VIF;
- стандартизация;
- PCA.

Особенность проекта состоит в том, что он использует локальный CSV-файл и не требует участия в соревнованиях Kaggle.

## 2. Описание датасета

Датасет содержит сведения о пингвинах.

Целевая переменная:

- `body_mass_g` — масса тела пингвина в граммах.

Используемые признаки:

### Числовые
- `culmen_length_mm`;
- `culmen_depth_mm`;
- `flipper_length_mm`.

### Категориальные
- `species`;
- `island`;
- `sex`.

Целевой столбец `species` не используется для классификации, поскольку поставленная задача требует регрессионных моделей и метрик RMSE, R² и MAPE. Поэтому `species` используется как категориальный предиктор, а прогнозируется `body_mass_g`.

## 3. Предварительный анализ данных

В начале программа:
- определяет размер датасета;
- проверяет типы данных;
- определяет количество пропусков;
- рассчитывает описательную статистику;
- строит распределения числовых переменных;
- анализирует зависимость массы тела от числовых признаков;
- сравнивает массу тела между видами.

Пропуски в признаках обрабатываются внутри pipeline. Для числовых признаков используется медиана, для категориальных — наиболее частое значение. Строки с отсутствующим `body_mass_g` удаляются перед обучением, поскольку целевую переменную нельзя корректно восстановить средствами стандартного preprocessing без отдельной модели имputation.

Таким образом, удаляются только 10 строк с пропущенной целевой переменной, а пропуски в признаках не приводят к потере наблюдений.

## 4. Разделение выборки

Данные разделяются на:
- 80% — тренировочная выборка;
- 20% — тестовая выборка.

Используется `random_state=42`, поэтому результаты можно воспроизвести.

Все параметры preprocessing и PCA обучаются только на тренировочной части данных.

## 5. Корреляционный анализ

Для числовых переменных строится корреляционная матрица.

Она позволяет оценить линейные связи между:
- длиной клюва;
- глубиной клюва;
- длиной ласты;
- массой тела.

Корреляционная матрица сохраняется в:

`results/correlation_matrix.csv`

График сохраняется в:

`results/figures/correlation_matrix.png`

## 6. Анализ мультиколлинеарности с помощью VIF

Для числовых предикторов рассчитывается Variance Inflation Factor.

В проекте VIF вычисляется для:
- `culmen_length_mm`;
- `culmen_depth_mm`;
- `flipper_length_mm`.

Результаты сохраняются в:

`results/vif.csv`

График:

`results/figures/vif.png`

VIF используется как диагностический показатель возможной мультиколлинеарности между предикторами.

## 7. Предварительная обработка

Для числовых признаков выполняются:
1. заполнение пропусков медианой;
2. стандартизация.

Для категориальных:
1. заполнение пропусков наиболее частым значением;
2. One-Hot Encoding;
3. удаление первой категории (`drop="first"`) для предотвращения идеальной линейной зависимости между dummy-признаками.

## 8. Модели до PCA

Рассматриваются три модели:

### Linear Regression

Обычная линейная регрессия без регуляризации.

### Ridge Regression

Ridge использует L2-регуляризацию. Значение параметра `alpha` выбирается с помощью GridSearchCV.

### Lasso Regression

Lasso использует L1-регуляризацию. Значение `alpha` также выбирается с помощью GridSearchCV.

## 9. Кросс-валидация

Для подбора гиперпараметров используется 5-fold cross-validation.

В качестве критерия выбора используется отрицательное RMSE (`neg_root_mean_squared_error`), которое преобразуется обратно в RMSE для интерпретации.

## 10. Метрики

### RMSE

Root Mean Squared Error показывает среднюю величину ошибки прогнозирования в единицах целевой переменной.

Чем меньше RMSE, тем меньше средняя величина ошибки.

### R²

Коэффициент детерминации показывает, какую долю вариации целевой переменной объясняет модель.

### MAPE

Mean Absolute Percentage Error показывает среднюю абсолютную процентную ошибку.

Для `body_mass_g` MAPE применим, поскольку масса тела пингвинов положительна.

## 11. PCA

После анализа исходных признаков выполняется уменьшение размерности.

Pipeline для PCA включает:

1. обработку пропусков;
2. One-Hot Encoding;
3. стандартизацию всех полученных признаков;
4. PCA.

Количество главных компонент выбирается автоматически так, чтобы сохранить не менее 95% общей дисперсии.
